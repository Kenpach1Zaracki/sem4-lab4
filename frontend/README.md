# Реестр инцидентов на производстве

SPA-приложение для учёта инцидентов в сфере промышленной безопасности.

## Технологии

- React
- react-router-dom
- axios
- json-server

## Установка и запуск

1. Установить зависимости:

```
npm install
```

2. Запустить json-server (в отдельном терминале):

```
json-server --watch db.json --port 5000
```

3. Запустить приложение:

```
npm start
```

Приложение откроется на http://localhost:3000

## Маршруты

- `/` — список инцидентов
- `/detail/:id` — просмотр и редактирование инцидента
- `/add` — добавление нового инцидента

## CRUD-операции

- GET — загрузка списка инцидентов
- POST — добавление нового инцидента
- PUT — обновление существующего инцидента
- DELETE — удаление инцидента
